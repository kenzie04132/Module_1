# Overview

This code is a Task Scheduler that allows the user to add tasks, remove tasks, and view the tasks they've created. The user will also get a message when they are viewing those tasks if a task is overdue or if there is still time to complete it. 

I made a task scheduler software because I was getting behind on schoolwork last semester and wanted to test out how I could organize my tasks in a new language, C#, that I decided to learn.
